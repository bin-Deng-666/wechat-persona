# 微信指令与设置菜单

微信中文指令是当前唯一的产品设置入口。iLink 不能发送可点击的原生按钮，菜单用一条纯文本消息回复，用户发送编号完成选择。

## 默认菜单

```text
⚙️ 聊天设置
当前人格：小助手

1  换人格 · 选一种聊天风格
2  换模型 · workbuddy/deepseek-v4.1-flash
3  个人记忆 · 已记下 3 条
4  表情库 · 4 张可用

5  新对话 · 从新话题开始
6  压缩对话 · 整理前面的内容

回复数字选择 · 0 关闭
菜单五分钟内有效，也可以直接继续聊天
```

不显示分条参数、网页链接或后台部署提示。主菜单按日常设置与对话操作留白分组，标题使用一个图标；每项带简短说明。帮助按常用入口、对话管理、表情用法分组，示例和导航提示放在末尾。人格、记忆和表情各有独立的简短子菜单，空数据提供自然的中文用法提示。长记忆只展示前八条摘要，单条预览有长度上限，底层完整内容不截断。

## 换模型

模型面板直接平铺 `provider/model`，不先选提供方，也不分页：目录来自宿主 `ctx.llm.listProviders()` 与 `listModels()`，顺序与 DSH 的模型选择器一致，有多少列多少。当前使用的模型标 `✓ 当前使用`；联系人没选过时显示宿主默认。一页列完意味着编号会到两三位数，所以菜单开着时接受 1–3 位数字（菜单关掉的普通消息不受影响）。

选择按联系人写进 `chats/<sha256(peerId)>/settings.json` 的 `model` 字段，与会话创建时的路由一起生效。模型是在建会话那一刻定下的，所以换模型会顺带开一段新会话（回复里写明第几段），旧记录保留。宿主没有 llm 目录时该面板只给说明，不显示空列表。图片能力也随之按联系人各自的模型判定。

## 中文触发词

| 指令 | 行为 |
|---|---|
| 设置 / 菜单 | 打开主菜单 |
| 帮助 | 回复全部中文触发指令、用途和例子 |
| 人格 | 打开人格选择菜单 |
| 人格 id | 直接切换指定人格 |
| 记忆 | 打开个人记忆菜单 |
| 表情 | 打开表情库 |
| 表情 收 名字 | 收藏刚收到的图片 |
| 表情 发 名字 | 发送指定表情 |
| 新对话 | 取消旧活动并开启新代次，历史保留 |
| 压缩 / 压缩对话 | 压缩当前对话的旧历史 |
| 状态 | 当前人格、对话段数、权限与最近活跃时间 |
| 停止 | 取消正在处理的任务和未发出的内容 |

旧的斜杠命令仍保留，如 `/menu`、`/settings`、`/help`、`/persona`。分条菜单和“分条”触发指令已移除；这些中文文本按普通聊天处理。模型和传输层的正常消息边界、超长文本处理仍由回复队列负责。

## 状态与执行

- 菜单按联系人隔离，五分钟无操作后失效，正常聊天自动关闭。
- 只消费有效菜单内的单个数字，兼容全角数字和末尾句号；“3 点开会”属于普通聊天。
- 子菜单的 `0` 或“返回”回到上一级，主菜单的 `0` 关闭；任何菜单可发送“关闭”退出。
- 清空记忆先显示确认页，只有再次确认才删除。取消返回记忆页。
- 审批答复优先于菜单编号，避免选项覆盖待处理的工具审批。
- 菜单与帮助各自整条发送，携带触发消息的 `context_token`，复用联系人队列和发送回执。
- 从菜单发起的压缩复用中文“压缩”执行路径，在入站循环外运行，允许“停止”取消；迟到反馈遵守输出取消和代次约束。

## 文件边界

`commands.ts` 管触发词和帮助，`menu.ts` 管纯文本视图与映射，`controls.ts` 管会话状态和动作执行，`channel.ts` 管消息调度。网页、小程序及其旧接线在 [../../archive/settings-clients/](../../archive/settings-clients/README.md)；当前插件不调用归档代码。
