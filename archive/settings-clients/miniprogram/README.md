# 已归档：原生微信小程序

本说明描述历史实现，不是当前插件入口。请先阅读 [归档说明](../README.md)。下面的 `npm run` 命令在 `archive/settings-clients/` 中运行；主项目中不再提供这些命令。

这是原生 WXML / WXSS / JavaScript 小程序，共 11 个页面，不是 web-view 网页容器。手机主入口为聊天、记忆、表情、我的；编辑进入独立页面，尽量减少首屏表单。

当前源码和接口已实现，仓库使用 `touristappid` 占位，`config.js` 的服务地址为空。**尚未上传、发布或完成微信开发者工具与真机验收。** 不填写虚假的 AppID 或临时隧道地址来声称已经可用。

## 接入需要

- 一个已注册微信小程序的 AppID。
- 一个实际可访问的固定 HTTPS 服务域名，反向代理到独立设置服务。电脑内网地址不能作为正式小程序服务地址。
- 在微信平台把同一个 HTTPS 域名添加到 `request` 和 `downloadFile` 合法域名。

本实现通过 bot 生成的短期绑定码确认联系人，不申请用户头像、手机号，不使用 AppSecret。AppID 仅用于小程序构建与发布，不是登录凭据。

在归档目录配置：

```bash
npm run configure:miniapp -- --appid wx你的AppID --api-base https://你的设置域名
npm run check:miniapp -- --require-config
```

然后用微信开发者工具导入本目录，执行编译、真机预览和上传。正式版是否可发布以微信平台审核结果为准。

## 使用

恢复历史服务后，可通过归档服务的本机 `node lib/settings.js pair` 获取 8 位绑定码。旧版微信“网页”入口也能生成绑定码，但当前插件已移除该入口。绑定后可从微信下拉“最近使用”或“我的小程序”进入，90 天内保持登录，服务重启不清除会话。

“我的 → 登录设备”可以撤销旧设备。“退出当前设备”只退出设置，不会退出 bot 的微信账号。

## 功能

- 聊天：人格选择、回复开关、默认分条与字数、在线时新对话 / 压缩 / 停止。
- 记忆：摘要、搜索与类型筛选、版本校验、原话来源、新增 / 修改 / 删除。
- 表情：图片网格、搜索与状态筛选、分页加载、原图预览、名称 / 描述 / 场景、共享 / 移出。
- 我的：bot 状态、人格管理、设备管理和与网页共用的使用帮助。

后台离线时页面明确显示连接失败；bot 离线但设置服务在线时，可以编辑数据，对话控制禁用。

## 权限与数据

浏览器使用 HttpOnly cookie，小程序使用独立设备 token，保存在微信小程序自身存储中。token 放在 `Authorization` 请求头，不拼进图片 URL。表情原图通过携带同一请求头的 `wx.downloadFile` 下载到临时路径，不制作无鉴权公开图片链接。

管理员和联系人权限由服务端校验。修改页面参数不能读取别人的记忆或表情，也不能提升为管理员。移出或删除、服务端失败时保持输入，不把失败显示成成功。

## 本地验证边界

`npm run check:miniapp` 检查页面声明、JS 语法、JSON 和 WXML 标签结构；这不等于微信编译通过。自动测试还通过真实 HTTP 服务验证了小程序 API 模块的绑定、读写及联系人隔离。微信专属组件、设备导航和视觉效果仍需开发者工具及真机验收。
